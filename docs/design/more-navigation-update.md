# More Navigation Update

- More page entries that already have concrete feature pages should be route-driven entries.
- The app bar should expose More child routes through plain breadcrumbs only, without dropdown menus inside the breadcrumb navigation.
- The app bar breadcrumb uses a home icon followed by the current page entry instead of repeating a large page title.
- Data actions use independent routes for import, export, backup, and restore while reusing the existing data feature component.
