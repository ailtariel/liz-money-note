# 本 App 前端实施细节

本文档记录 Liz Money Note 当前移动端记账 App 的产品定位、信息架构、页面内容和交互行为。

本文档不规定具体字体、颜色、token、间距、圆角、阴影、typography、Vuetify defaults 或组件视觉样式。整体 UI 重构的具体 Vuetify 设计系统以 `docs/design/style-design-system.md` 为准。

仓库级 App 规则见 `AI-coding-specification/app-rules.md`，前端架构规则见 `AI-coding-specification/front-end.md`。Vuetify 通用能力选择、theme/defaults/scoped CSS 等原则以 Vuetify skill 为准，不在本文档重复。

## 产品定位

- 产品形态：Android 优先的移动端记账 App。
- 技术栈：Vue 3、Vuetify、Capacitor APK、vue-i18n。
- 目标设计尺寸：430 × 932，DPI 3。
- 设计目标：这是移动端产品，不是 PC 页面适配移动端。

## 应用范围

- 目标平台优先级：Android 移动端优先。
- 新增流水当前作为全屏 Dialog 打开，不作为独立路由。

## 一级导航

底部导航固定 4 个入口：

- 流水。
- 统计。
- 资产。
- 更多。

## 流水页面

顶部区域：

- 使用 app bar。
- 显示“流水”。
- 显示搜索按钮。
- 显示筛选按钮。
- 不在 app bar 放置新增按钮；新增流水使用底部导航上方正中的页面主操作按钮。
- 不显示大量工具栏菜单或 PC 风格菜单栏。

月度概览：

- 顶部显示一张概览卡片。
- 展示收入、支出、结余。
- 当当前流水涉及多种货币时，收入和支出按货币分别显示，每种货币一行。
- 某个货币的收入或支出合计为 0 时仍显示 `0.00`。
- 金额统一使用货币代码，不混用本地货币符号。

筛选：

- 不使用多个 Select、多行表单或日期输入框堆叠。
- 使用 Chip 作为筛选入口。
- 账本筛选从 summary 区域进入，使用列表选择。
- 账户筛选使用独立列表。
- 交易类型筛选使用独立列表，显示名称为“交易类型”。
- Tag 筛选使用独立窗口，以 Chip 形式支持多选 enable / disable。
- 已选 Tag 在筛选器下方单独成行展示，并支持清空或移除单个 Tag。
- 日期筛选使用独立窗口，支持 Date Picker 选择范围，并提供“本月 / 本年”快速切换。
- 使用 Vuetify 日期组件时，应通过 `useDate()` 的 `parseISO` 和 `toISO` 统一标准化日期字符串；组件内部 Date 对象不应直接泄露为业务存储格式。

## 流水列表

不要使用：

- Data table。
- 分页。
- 表格列。
- `1-10 of 89` 这类 PC 分页文案。

不要出现桌面表格结构：

```text
日期 | 类型 | 账本 | 账户 | 金额 | Tag
```

列表按日期分组：

- 今天。
- 昨天。
- 5 月 18 日。
- 5 月 17 日。

每组显示当日收入和当日支出。

流水卡片每条显示：

- 分类图标。
- 标题。
- 账户。
- 账本。
- Tag。
- 时间。
- 金额。

当选择了特定账本时，流水卡片内不再重复显示账本。

当选择了特定账户时，流水卡片内不再重复显示账户。

卡片布局：

- 左侧显示分类图标。
- 右侧内容分三行。
- 第一行显示标题。
- 第二行左侧显示账本和 Tag，右侧显示金额。
- 第三行左侧显示时间，右侧显示账户。

列表中不要直接显示：

- ID。
- 创建时间。
- 更新时间。
- 删除按钮。
- 编辑按钮。
- 三点菜单。

点击整行打开详情 Bottom Sheet。

详情 Bottom Sheet 显示：

- 金额。
- 分类。
- 账户。
- 账本。
- Tag。
- 时间。
- 备注。

底部操作：

- 编辑。
- 复制。
- 删除。

## 新增流水 Dialog

新增流水当前作为全屏 Dialog 实现。

顶部：

- 返回按钮。
- 标题“新增流水”。
- 模板按钮可选。

收支切换：

- 支出。
- 收入。
- 转账。
- 使用 Tab。

金额输入：

- 金额是页面视觉中心。
- 应明显大于其它元素。
- 使用货币代码。
- 支持计算器按钮。

分类选择：

- 不使用下拉框。
- 使用横向分类选择或图标宫格。
- 示例：餐饮、购物、交通、汽车、娱乐、更多。

账户：

- 不使用 Select。
- 使用账户卡片或列表项。
- 显示账户名称和余额。
- 点击进入选择页或选择区域。

账本：

- 使用列表项。
- 点击进入选择页或选择区域。

Tag：

- 使用 Chip。
- 支持添加 Tag。

日期时间：

- 使用列表项显示日期和时间。
- 点击打开 Date Picker 或 Time Picker。
- 使用 Vuetify 日期组件时，应通过 `useDate()` 的 `parseISO` 和 `toISO` 统一标准化日期字符串；保存前统一转换为业务层约定格式。

备注：

- 使用简单 Textarea。
- 不需要复杂编辑器。

保存按钮：

- 固定底部。
- 始终可见。
- 不跟随页面内容滚动。

## 统计页面

统计是第二高频页面。

实现边界：

- 统计页作为独立 `statistics` 模块实现，不放在 `transactions` 模块内。
- 统计模块可以读取流水、账本、账户、Tag、货币和汇率数据，但统计页自身的页面状态、图表组织和统计展示逻辑应归属 `src/modules/statistics/`。

主要展示：

- 本月收支。
- 分类占比。
- 月趋势。

不要堆大量报表。

## 资产页面

展示总资产。

下面以卡片形式展示：

- 现金。
- 银行卡。
- 微信。
- 支付宝。
- 信用卡。

不要使用表格。

## 账本与账户管理

- 使用适合移动端单手操作的卡片展示，不使用管理后台式表格。
- 卡片信息层级依次为名称、类型或说明、状态和余额，操作区与内容区分离。
- 账户不再提供新的归档操作；历史已归档账户显示兼容状态，并提供恢复入口。
- 删除账户前必须确认。存在历史流水、周期事件引用，或关联账本没有其它启用账户时，阻止删除并显示明确原因。
- 安全删除账户只删除账户及账本关联，不删除历史流水或周期事件。
- 账本继续沿用既有归档、恢复和破坏性删除语义；本次只统一管理卡片和编辑器的信息层级。

## 更多页面

低频功能全部放到更多页面。

基础资料：

- 账本。
- 账户。
- Tag。
- 周期。

数据：

- 导入。
- 导出。
- 备份。
- 恢复。

设置：

- 主题。
- 默认货币。
- 系统。
- 关于。

系统：

- 清理缓存。
- 清理浏览器 CacheStorage 和 Android WebView 缓存。
- 不删除 SQLite 业务数据、导入数据、账本、账户、流水或用户偏好。
- 清理缓存前必须确认，并在描述中明确不会删除数据库数据。
- 重置数据库。
- 重置数据库必须确认；仅应在数据损坏时使用，并提示用户提前备份数据。
