# 记账 App 移动端 UI 重构设计

## 目标

设计一个真正的 Android 移动端记账 App。

技术栈：

- Vue3
- Vuetify
- Capacitor APK
- Android 优先

设计尺寸：

- 430 × 932
- DPI 3

注意：

这不是 PC 页面适配移动端。

不要把桌面版表格压缩到手机宽度。

请从移动端产品角度重新设计信息架构和交互。

## 设计稿图片在docs\UI design。

# 设计原则

优先级：

1. 快速查看流水
2. 快速新增流水
3. 单手操作
4. 降低信息密度
5. 减少点击次数
6. 如果某个页面第一眼看上去像 Excel、数据库、ERP 或后台管理系统，那么说明设计失败，请重新设计。
7. 尽可能使用vuetify组件样式
8. 通用样式，例如primary color / success color / font size / border radius，等等，尽量都放到vuetify全局设置里，而不要在每个页面单独写样式

用户最关心的是：

- 花了什么钱
- 收了什么钱
- 还有多少钱

而不是：

- 数据库字段
- 表格列
- 管理后台风格界面

底部导航固定 4 个入口：

- 流水

- 加号按钮放到底栏
- 底栏横向滚动
- 超过 5 个菜单

使用：

- v-bottom-navigation

---

# 新增流水入口

新增流水是整个系统最高频操作。

使用：

右下角 FAB 浮动按钮

不要：

- 放在底部导航
- 放在顶部菜单
- 放在更多页面

FAB 点击后：

打开新增流水页面

使用：

- v-fab
- position: fixed

# 流水页面

## 顶部

使用：

v-app-bar
